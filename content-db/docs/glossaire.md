# Glossaire

| Mot | En une phrase |
| --- | --- |
| **Activité** | Une étape d'une séance (dire bonjour, répéter un mot, toucher une image…) |
| **Bibliothèque** (`library/`) | Les documents d'édition que tu écris : la source de vérité |
| **Bucket** | Un dossier de fichiers dans Supabase Storage |
| **CECRL / CEFR** | Le cadre européen des niveaux de langue (Pré-A1, A1, A2…) |
| **Chunk** | Une expression apprise d'un bloc (« thank you », « what's your name? ») |
| **Déclencheur (trigger)** | Une règle dans la base qui s'exécute à chaque écriture (vérifier un schéma, refuser une modification) |
| **Document** | Un objet JSON complet : une séance, un mot, un objectif, un média ou le programme |
| **Document d'édition** | La version que tu écris, qui cite les autres documents par id |
| **Fichier livré** | La version autonome fabriquée par la publication, au format de Viven, figée |
| **Figé** | Publié une fois pour toutes : on ne le modifie plus, on publie la version suivante |
| **GSE** | Global Scale of English (Pearson) : des objectifs notés de 10 à 90 |
| **id** | Le nom permanent d'un élément (`w_hello`), qui ne change jamais |
| **Index** | Le résumé fabriqué à la publication (`published/index.json`) : qui utilise quoi |
| **JSON** | Un format texte pour décrire des données structurées, lu par tous les langages |
| **JSONB** | Le type de colonne Postgres qui stocke un document JSON et permet de le chercher |
| **Leitner (boîtes de)** | Méthode de révision espacée : un mot réussi revient plus tard, un mot raté revient vite |
| **Moteur** | Le programme de Viven qui joue les séances et décide |
| **pg_jsonschema** | Extension Supabase qui vérifie un JSON contre son schéma dans la base |
| **Progression** | Ce que chaque enfant a fait et sait (base de Viven) |
| **Publication** | L'étape qui vérifie et fabrique les fichiers livrés |
| **Rattrapage** (`retry_only`) | Une version plus facile d'un exercice raté, jouée avant l'au revoir |
| **Relationnel** | Une base faite de tableaux à colonnes fixes reliés entre eux |
| **Révision espacée** | Revoir un mot à intervalles de plus en plus longs pour bien le retenir |
| **RLS** | Row Level Security : les règles Supabase de qui peut lire ou écrire quoi |
| **Schéma JSON** | Le fichier qui décrit la forme obligatoire d'un document |
| **Séance** | Une leçon de 8 à 10 minutes, avec 4 mots nouveaux |
| **Storage** | L'espace de fichiers de Supabase (images, chansons, vidéos) |
| **Supabase** | Le service de base de données (Postgres) et de fichiers utilisé par l'équipe |
| **Variante acceptée** | Ce que la reconnaissance vocale peut écrire à la place du mot et qu'on accepte (« know » pour « no ») |
| **Version** | Le numéro d'un document, +1 à chaque publication d'un changement |
