## Chanson Colours (unité 2) pour Suno

**Style** (champ « Style of Music ») :

> children's nursery song, cheerful, simple melody, slow tempo 90 bpm, ukulele and xylophone, clear female voice, very clear English pronunciation, short, for 5 year olds

**Paroles** (champ « Lyrics », mode Custom) :

```
[Verse]
Red and blue, yellow too!
Green, green, I like green!

[Verse]
Red and blue, yellow too!
Green, green, I like green!
```

**Titre :** Colours Song (Pixo)

**Minutage prévu** (dans la fiche `library/media/m_song_colours.json`) :

| Ligne | start_ms | end_ms |
| --- | --- | --- |
| Red and blue, yellow too! | 0 | 3500 |
| Green, green, I like green! | 3500 | 7000 |
| Red and blue, yellow too! | 7000 | 10500 |
| Green, green, I like green! | 10500 | 14000 |

Suno ne respecte pas un minutage exact : une fois le MP3 fait, il faut **remesurer** les temps sur le vrai fichier (Claude peut le faire automatiquement avec un outil de transcription, comme pour la chanson Hello), puis mettre à jour `lyrics` et `duration_ms` dans la fiche. Rappel licence : plan gratuit = tests seulement ; plan payant pour de vrais enfants.
